Now let's talk about modeling.

Here is an example script that does some basic Marketing Mixed Modeling, or MMMs.

This particular modeling script is made for this demo where you can run it as a regular R script, from the command line with command line arguments, and gets run by the shiny application we will show later.

This isn't the best way to do an official deployment,
but gives a lot more flexibility as a demo.


Let's talk a bit about MMMs. There's a few things that make MMMs special:
there's a temporal time-series component, there are carry over effects (meaning money spent now does not always mean immediate revenue), and there are diminishing returns where impact may decrease with spend.

Here we'll fit 2 different models, a linear regression model and a weekly informative bayesian linear regression model. and then we'll fit these same models with the carryover and diminishing returns transformations for a total of 4 models.
